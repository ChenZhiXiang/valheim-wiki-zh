# 英灵神殿维基

发布版本：1.0.4  
包类型：线上发布版

## 工程简介

本工程将英灵神殿（Valheim）维基内容整理为可在浏览器阅读的中文静态站点，保留英文内容供对照，支持离线查阅和线上部署。可更新版还提供原站更新检查、增量下载和 AI 译文导入工具，便于持续维护。

## 主要功能

- 浏览中文与英文维基页面、图片和站内链接。
- 使用中英文标题、别名搜索，并可按需启用全文搜索。
- 线上部署后可检查站点版本，发现新版时提示刷新。

## 目录结构

以下路径相对于本 README 所在目录：

- `index.html`：网站首页。
- `pages/`：维基条目页面。
- `assets/`：图片、样式、脚本与搜索索引等静态资源。
- `version.json`：站点发布版本。
- `bundle.json`：打包模式、时间及文件清单。

## 使用方式

将 ZIP 完整解压后，把全部内容上传到网站发布目录，入口为根目录的 `index.html`。请同时上传 `version.json`、`pages/`、`assets/` 和 `.nojekyll`；本包不包含更新工具。

## 内容来源与许可

内容整理自 Valheim Wiki。原站来源与内容许可信息保留在各网页页脚；相关运行时与依赖的许可信息保留在原目录。
