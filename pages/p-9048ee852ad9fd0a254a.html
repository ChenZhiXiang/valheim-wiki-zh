沼泽钥匙是击败古树长老后的掉落物，用于开启幽暗沼泽生态区域中的地下圣堂。

获取方式

  • 由黑暗林山中的古树长老掉落。

用途

沼泽钥匙开启幽暗沼泽中的地下圣堂。每座墓穴首次开门需在背包，之后重入不需要，可无限使用。

Swamp key is an item dropped from The Elder after defeating him. It is used to open Sunken Crypts in Swamp biomes.

Availability

  • Dropped from The Elder in the Black Forest.

Usage

The Swamp Key is used to unlock Sunken Crypts inside the Swamp. It must be in the player's inventory the first time each crypt gate is opened, but is no longer needed to re-enter the same crypt. It can be used an unlimited amount of times.
