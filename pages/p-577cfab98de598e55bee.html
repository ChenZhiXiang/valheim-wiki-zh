全局标记用于记录游戏世界进度。

首领标记

首领标记决定哪些事件和生成处于启用状态。

  • defeated_bonemass ——击杀时设置 邪骨恶灵
  • defeated_gdking ——击杀时设置 古树长老
  • defeated_goblinking ——击杀时设置 亚格鲁斯
  • defeated_dragon ——击杀时设置 冰霜龙母
  • defeated_eikthyr ——击杀时设置 赤血灵鹿
  • defeated_queen ——击杀时设置 蛊虫之后
  • defeated_fader ——击杀时设置 青焰龙王
  • defeated_serpent ——击杀以下生物时设置 蛟龙
  • KilledTroll ——击杀以下生物时设置 巨魔
  • killed_surtling ——击杀以下生物时设置 焰灵
  • KilledBat ——击杀以下生物时设置 邪蝠

世界修正标记

倍率数值是默认速率的百分比：100为正常，50为一半，200为两倍。开关标记存在即启用；部分标记也接受数值，由代码检查。

（据英灵神殿0.217.29版，网络版本17，2023年十一月12日；编写中，以下部分标记仍待定义及澄清。）

  • activeBosses
  • AdrenalineRate：调整血怒获取速率，数值越高获得越多。
  • AllPiecesUnlocked：解锁全部建筑配方。
  • AllRecipesUnlocked：解锁全部制作配方。
  • 计数
  • DeathDeleteItems：死亡时永久删除全部物品。
  • DeathDeleteUnequipped：死亡时彻底删除未装备物品。
  • DeathKeepEquip：玩家死亡时保留已装备物品。
  • DeathSkillsReset：死亡时清空全部技能。
  • DeathKeepInventory：死亡时不生成墓碑，并保留背包物品。
  • DungeonBuild：设置后允许在地下城内建造，如墓穴、坟墓等。
  • EnemyDamage：生物对玩家及其他生物造成的伤害，不影响建筑伤害。
  • EnemyLevelUpRate：生物获得星级的概率。例如200会使生物有20%概率升至1星，其中再有20%概率升至2星，最终实际概率分别为16%和4%。
  • EnemySpeedSize：修改生物尺寸及速度。
  • EitrRate：调整埃达之能相关速率。
  • DurabilityRate：调整耐久消耗速率，数值越低越耐用。
  • FoodRate：调整食物增益衰减速率，数值越低持续越久。
  • CarryWeightRate：调整物品的有效重量，数值越高可携带量越大。
  • EventRate：袭击触发频率与概率。100为标准值，即每46分钟有20%概率触发。例如50会使每23分钟有40%概率触发。
  • Fire：启用火灾世界修正，使木材能起火，并在整个世界蔓延，而不限于灰烬之地。
  • MoveStaminaRate：调整奔跑、跳跃等移动活动的耐力消耗速率，数值越低消耗越少。
  • NoBossPortals：首领存在时禁用传送门。
  • NoBuildCost：建造无需资源。
  • NoCraftCost：制作无需资源。
  • NoMap：禁用所有玩家地图。
  • NoPortals：禁用所有玩家传送门。
  • NoWorkbench
  • PassiveMobs：敌人只有受到攻击才会转为敌对，也不会主动攻击建筑。
  • PlayerDamage：玩家对生物造成的伤害。
  • PlayerEvents：设置后，袭击事件按玩家进度而非世界进度触发。
  • 预设
  • ResourceRate：调整资源掉落数量，数值越高资源越丰富。
  • SkillGainRate：调整技能经验获取倍率，数值越高提升越快。
  • SkillReductionRate：调整普通死亡的技能损失倍率，数值越低损失越少。
  • StaminaRate：调整一般耐力消耗速率，数值越低消耗越少。
  • StaminaRegenRate：调整耐力恢复速率，数值越高恢复越快。
  • TeleportAll
  • WorldLevel
  • WorldLevelLockedTools

控制台命令

可用以下控制台命令修改全局标记：

  • listkeys：显示当前设置的全局标记。
  • setkey [name] [value]：添加指定标记，可选择附带指定数值。
  • resetkeys：移除全部标记。
  • removekey [name]：移除指定标记。

Global keys are used to track progress in game worlds.

Boss Keys

Boss keys determine which events and spawns are active.

  • defeated_bonemass — Set when killing Bonemass
  • defeated_gdking — Set when killing The Elder
  • defeated_goblinking — Set when killing Yagluth
  • defeated_dragon — Set when killing Moder
  • defeated_eikthyr — Set when killing Eikthyr
  • defeated_queen — Set when killing The Queen
  • defeated_fader — Set when killing Fader
  • defeated_serpent — Set when killing a Serpent
  • KilledTroll — Set when killing a Troll
  • killed_surtling — Set when killing a Surtling
  • KilledBat — Set when killing a Bat

World Modifier Keys

Scalar values are percentages of the default rate: 100 is normal, 50 is half, and 200 is double. Toggle keys are enabled by being present; some keys also accept a numeric value where the code checks one.

(( Taken from version Valheim 0.217.29 (network version 17), 12th November 2023; WIP Some keys listed below still require definition and clarification))

  • activeBosses
  • AdrenalineRate: Multiplies rate at which adrenaline is gained (higher is more gained)
  • AllPiecesUnlocked: All building recipes are unlocked
  • AllRecipesUnlocked: All crafting recipes are unlocked
  • Count
  • DeathDeleteItems: All items are permanently deleted on death
  • DeathDeleteUnequipped: Unequipped items are removed completely on death
  • DeathKeepEquip: Equipped items are retained when the players dies
  • DeathSkillsReset: All skills are cleared on death.
  • DeathKeepInventory: No tombstone is created and the inventory is kept on death.
  • DungeonBuild: When set, allows the building of structures inside dungeons (e.g crypts, tombs etc)
  • EnemyDamage: Damage done by mobs to players and other mobs (not structures)
  • EnemyLevelUpRate: The chances of mobs being starred. eg: 200 would give 20% chances of a creature being upgraded to 1 star and then 20% of those being further upgraded to 2 star (resulting in 16% and 4% chances in real terms)
  • EnemySpeedSize: Modifies the size and speed of mobs
  • EitrRate: Multiplies eitr-related rates
  • DurabilityRate: Multiplies rate of durability consumption (lower is more durable)
  • FoodRate: Multiplies rate of food buff decay (lower is longer lasting)
  • CarryWeightRate: Multiplies effective weight of items (higher is greater capacity)
  • EventRate: The frequency and chance of a raid being triggered with 100 being the standard 20% chance every 46 minutes. eg: 50 would give a 40% chance of a raid every 23 minutes
  • Fire: Enable fire hazards world modifier, whereby wood can catch fire and spread throughout the whole world, not just in the Ashlands
  • MoveStaminaRate: Multiplies rate stamina is expended for movement based activities such as running and jumping (lower is less expenditure)
  • NoBossPortals: Portals are disabled while bosses are active
  • NoBuildCost: Resources are not required when building
  • NoCraftCost: Resources are not required when crafting
  • NoMap: Disables map for all players.
  • NoPortals: Disables portals for all players.
  • NoWorkbench
  • PassiveMobs - Enemies do not enter their aggressive state unless attacked. This includes not attacking structures.
  • PlayerDamage: Damage done by players to mobs
  • PlayerEvents: When set, raid events are player-based rather than world-based
  • Preset
  • ResourceRate: Multiplies rate at which resources are dropped (higher is more plentiful)
  • SkillGainRate: Multiplies skill gain (higher is faster improvement)
  • SkillReductionRate: Multiplies ordinary death skill reduction (lower is less lost)
  • StaminaRate: Multiplies general stamina use rate (lower is less spent)
  • StaminaRegenRate: Multiplies rate at which stamina is regenerated (higher is faster replenishment)
  • TeleportAll
  • WorldLevel
  • WorldLevelLockedTools

Console commands

Global keys can be manipulated with following console commands:

  • listkeys: Shows currently set global keys
  • setkey [name] [value]: Adds the specified key, optionally with the specified value
  • resetkeys: Removes all keys
  • removekey [name]: Removes the specified key.
