商人是以钱币出售物品的友善角色，也可用贵重物品换金币。

有三个商人:

  • 黑暗林山中的霍尔德。
  • 青青草原中的希尔德。
  • 幽暗沼泽中的沼泽女巫。

位置

每世界每类商人仅一名，各有多个候选位置。靠近任一会永久锁定，相关区域生成时，可能在320至453米外发生，约默认小地图范围两倍。发现后地图出现商人图标。

贵重物品

贵重物品是可在任意商人换金币的物品类别。

各商人价格相同，均接受所有贵重物品，卖出后无法买回。

Traders are NPCs that sell items in exchange for  Coins. They can also exchange valuables for coins.

There are three traders:

  • Haldor found in the Black Forest.
  • Hildir found in the Meadows.
  • The Bog Witch found in the Swamp.

Location

There can only be one merchant of each type in a world. Each trader has multiple possible spawn locations. Approaching any of these locations will permanently place the trader there. This can happen from 320 to 453 meters away (about twice of the default minimap range) when the related Zones are generated. When discovered, the trader icon will appear on the world map.

Valuables

Valuables is a category of items which can be exchanged for Coins at any of the traders.

There is no price difference between traders and they all accept all valuables. Once sold, valuable items cannot be bought back from traders.
