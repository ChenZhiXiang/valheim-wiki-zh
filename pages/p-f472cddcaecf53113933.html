锄头可抬高或平整地面，也可铺铺平及石铺路地面装饰，形成可见路径。

获取方式

可在工作台制作。

使用方法

高效平整有两个要点：按Shift点击，以准星所指地面高度为基准；不按Shift，则默认以玩家脚下高度为基准。

右键打开其他操作菜单，类似工具锤。部分操作有额外要求，例如每次抬地需2x石头，且附近有工作台。

说明

  • 可略微降低地面。最早可明显降低地面的工具参见鹿角镐。
  • “平整地面”以玩家位置为基准。玩家站得更高则抬高选中地面，站得更低则降低，从而平整至玩家所在高度。
  • 地面升降最大约15-20单位，基于世界生成时确定的地形网格高度。网格高度因地形而异，例如山地会更高。
  • 用锄头抬起土柱，可建比平地基础更大的石建筑。每块接触土柱的石块都算新基础，因此呈蓝色。

The Hoe is a tool that can be used to elevate or level the ground. It can also be used to apply the Pathen and Paved road ground decorations to an area, visually creating a path for players to walk on.

Contents

  • 1 Availability
  • 2 How to use
  • 3 Upgrade information
  • 4 Notes
  • 5 Gallery

Availability

It can be crafted in the Workbench.

How to use

To more effectively level the ground there are two things to keep in mind. Shift-clicking attaches the hoe to the level of ground it is pointed at. When not shift clicked it defaults the hoe to the level of ground the player is standing on.

Right-clicking opens a menu for other operations, similar to the Hammer. Some operation have additional requirements, for example raising ground requires 2xStone per operation and a workbench in the players vicinity.

Notes

  • It can lower the ground but only a little. For the first item available to lower the ground, please see Antler Pickaxe.
  • In the "level ground" option the player's position is what the selected terrain is compared to. Therefore, it will raise the selected terrain if the player's position is higher, and lower it, if the player is standing on lower ground. Thus evening out the terrain compared to the player's location.
  • Raising and lowering the ground has a maximum allowable amount around 15-20 units based on the mesh shape height established when the world is created. Mesh shape height varies; for example, it may elevate for mountains
  • By using the hoe to elevate pillars of earth, players can create much larger stone structures than by building from a flat foundation. Each stone block attached to the earth pillar counts as a new foundation, and is therefore "blue".
