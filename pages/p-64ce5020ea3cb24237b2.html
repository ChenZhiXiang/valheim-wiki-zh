物品架是装饰设施，可展示战利品及其他收集到的资源，有垂直和水平两种变体。

用途

可以放在物品架上的物品：

  • 全部 食物 除外 蜂蜜 (水平的仅限)
  • 全部 炸弹 (另加) 玄武岩炸弹)
  • 上古种子
  • 灰烬刚鬣蛋
  • 理发套件
  • 桶箍

  • 鸡蛋
  • 鱼
  • 丑地精图腾
  • 希尔德的 帽子
  • 希尔德的 箱子（仅水平架）
  • 蜜酒 (水平的仅限)
  • 仲夏之冠
  • 熔岩之核
  • 淡红银矿石粉
  • 马鞍
  • 镰刀
  • 镰刀把
  • 封印破除者
  • 盾
  • 焰灵之核
  • 沼泽密钥
  • 蓟草
  • 工具

  • 饰物

  • 武器 不包括箭头 与 弩箭
  • 圣诞帽

Item stands are decorative structures that can be used to display trophies or other resources a player may have collected. They come in two variants, vertical and horizontal.

Usage

Items that can be put on an item stand:

  • All Food except Honey (horizontal only)
  • All Bombs (also Basalt Bomb)
  • Ancient Seed
  • Asksvin egg
  • Barber Kit
  • Barrel Hoops
  • Bell
  • Black Core
  • Celestial Feather
  • Dandelion
  • Dragon Egg
  • Dragon Tear
  • Dverger Circlet
  • Dvergr Tankard
  • Egg
  • Fish
  • Fuling Totem
  • Hildir's hats
  • Hildir's chests (horizontal only)
  • Meads (horizontal only)
  • Midsummer Crown
  • Molten Core
  • Proustite Powder
  • Saddles
  • Scythe
  • Scythe Handle
  • Sealbreaker
  • Shields
  • Surtling Core
  • Swamp Key
  • Thistle
  • Tools
  • Torn Spirit
  • Trinkets
  • Trophies
  • Volture Egg
  • Weapons excluding Arrows and Bolts
  • Yule Hat

Items that cannot be put on an item stand:

  • Accessories
  • Armor (excluding the ones above)
  • Arrows
  • Askvin Skeleton components
  • Bell Fragment
  • Black Marble
  • Bolts
  • Charcoal Resin
  • Crystal
  • Dvergr Extractor

Notes

  • Rotating the vertical item stand will flip horizontally but not vertically; so "crossed swords" are not possible at this time.
