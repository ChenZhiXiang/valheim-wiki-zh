用途

所有战利品都有一些共同用途：

  • 可放物品架装饰。
  • 可用于设置弩炮攻击对象。
  • 所有战利品在湮灭者使用，每个提供1木炭。

部分战利品有特殊用途：

  • 部分用于制作配方。
  • 部分用于召唤弃誓者。

每位弃誓者被击败后，必定掉落特殊战利品。将其带回献祭石阵，可解锁新的放逐之力。

轻甲

以下战利品会发出微弱光芒：

  • 焰灵战利品发浅橙光。
  • 石魔战利品会发出青色光芒。将其放在运作中的冶炼炉附近的物品展示架上，光芒会明亮得多。
  • 布伦娜战利品发橙光。

Usage

All trophies have some shared uses:

  • They can be attached to Item Stands to serve as decorations.
  • They can be used to program the Ballista.
  • All trophies will give 1 Coal per trophy if used in an Obliterator.

Some trophies have special usage:

  • Some are used as crafting ingredients.
  • Some are used to summon Forsaken.

Each Forsaken is guaranteed to drop a special trophy when defeated that can be returned to the Sacrificial Stones to unlock a new Forsaken power.

Notes

  1. ↑ Serpent trophies sink to the bottom of the ocean, so it is best to kill a Serpent close to the shore. It can be done by dragging the Serpent with an Abyssal Harpoon.
  2. ↑ 2.0 2.1 A full stack of Serpent or Bonemaw trophies or meat is the heaviest single-storage-space weight in Valheim, at 500 weight units.
  3. ↑ The Dvergr trophy drops from all creatures of the Dvergr race, that includes Dvergr Rogue, Dvergr Mage and Ashlands Dvergr. It is the only trophy to drop from multiple creatures.
  4. ↑ 4.0 4.1 4.2 It is possible to create a decorative skeleton by combining a Warrior trophy (head), a Warlock trophy (body), and a Marksman trophy (leg) on Item stands.

Light

The following trophies emit a small light:

  •  Surtling Trophy emits a light orange light.
  •  Stone Golem Trophy emits a cyan light. It will glow much more brightly if it is placed on an item stand near an active smelter.
  •  Brenna Trophy emits an orange light.
